# V2 iPhone 手動テスト

テスト用Supabaseに接続したiPhoneのV2ビルドで、確認した項目にチェックを入れる。

## 初回生成とカレンダー

- [ ] 手順　カレンダーの読み取りを許可し、計画のない今日を開く。アプリを完全終了してもう一度開く。

      期待結果　初回だけ保存され、再起動後も同じ計画を表示する。

- [ ] 手順　計画のない未来日を選ぶ。別日に移ってから、最初の日に戻る。

      期待結果　その未来日を初めて開いたときに計画が生成される。戻ったときは保存済みの計画を表示する。

- [ ] 手順　iPhoneの設定でカレンダーの許可を取り消し、計画のない日を開く。「この日はアプリ内予定のみ使う」を押し、後でiPhoneの設定から許可を戻す。

      期待結果　承認までは生成せず、限定モードには注意が表示される。許可を戻すと端末予定を再取得できる。

- [ ] 手順　固定予定、移動時間、時間帯を指定した食事を登録する。生成後に、その計画と重なるiPhone予定を追加してPlannerを開き直す。

      期待結果　作業枠は固定予定・移動時間を避け、食事は指定範囲内に入る。追加した端末予定との衝突が表示され、保存済み計画は承認するまで変わらない。

- [ ] 手順　固定予定の少ない日と、固定予定で夕方の空きが分断された日を開く。

      期待結果　自由時間は夕方・夜のまとまりを優先し、必要に応じて分割する。Task間の余裕は別の時間に確保される。

## Goals、Tasks、作業枠

- [ ] 手順　期限なしGoalとGoalに紐付くTaskを作る。別のTaskをGoalなしで保存する。

      期待結果　両方のTaskが保存され、Goalを手動で完了にできる。

- [ ] 手順　単発・毎日・月水金の週3回Taskを作る。水曜の週3回Taskを未実施のままにする。同じ金曜の2枠を完了する。

      期待結果　水曜分は木曜に自動追加されず、金曜の完了は週の実績で1日分。翌週も月水金が対象で、未完了の単発Taskは候補に残る。

- [ ] 手順　昨日が期限のTaskを開く。期限編集・再計画・完了を別々のTaskで試す。

      期待結果　警告が出て自動配置は保留される。再計画は確認後に反映し、完了したTaskは通常候補から外れる。

- [ ] 手順　終了時刻を過ぎた枠を開き、完了する。Tasks画面でそのTask本体を確認する。

      期待結果　操作前は未確認。操作後はその作業枠の完了が記録され、Task本体の状態は維持される。

- [ ] 手順　同じTaskに複数枠のある日で1枠を選び、「あとで」の「変更を確認」を一度閉じてから再度開いて承認する。別の枠で「今日はしない」を選ぶ。

      期待結果　閉じた時点では元の計画が残り、承認後は当日の将来時刻へ移るか、空きなしの案内が出る。「今日はしない」の対象範囲が画面に表示される。

- [ ] 手順　作業枠をドラッグで移動し、別の枠の時刻を数値入力で変更する。変更案を承認し、どちらかの固定を解除する。

      期待結果　編集した枠だけが変わって自動固定される。Task本体の基本作業時間は維持され、固定解除の状態も保存される。

- [ ] 手順　再計画のプレビューを開き、別端末またはiPhoneカレンダーで対象の予定を更新してから承認する。

      期待結果　古いプレビューは保存されず、最新状態で確認できる。

- [ ] 手順　SettingsでTask間の余裕とタイムゾーンを変更し、次に計画のない日を開く。

      期待結果　変更後のタイムゾーンで日付を判定し、新規の配置に設定した余裕が反映される。

## AIチャットと下書き

- [ ] 手順　「新規会話」で名前を入力して作成し、GoalとTaskを提案させ、追加メッセージで内容を調整する。アプリを再起動して会話一覧から開き直す。

      期待結果　会話と下書きが復元され、承認前はGoals・Tasksの本体に追加されていない。

- [ ] 手順　下書きをフォームで編集して保存し、「この下書きについて相談」から修正を依頼する。一部の項目だけを選び、承認を連続で押す。

      期待結果　フォームの変更が後続の文脈に反映される。選択した項目だけが整合性を保って1回保存される。

- [ ] 手順　既存Taskの編集案を開く。別画面で先にTaskを変更した後、元の案を承認する。

      期待結果　変更前後が表示され、先に保存された変更を古い案で上書きしない。下書きは再編集できる。

- [ ] 手順　AI未設定の検証環境、または上限に達した検証アカウントでチャットを開く。通信が失敗する状況でも画面を確認する。

      期待結果　理由と使用可能な操作が表示され、AIが使えなくても保存済み下書き、Goals・Tasks、ルールベース計画を使える。予算画面に推定値であることが示される。

## iPhoneでの操作

- [ ] 手順　iPhoneの文字サイズを拡大し、VoiceOverで作業枠と承認ボタンに移動する。ドラッグの代わりに時刻入力を使う。

      期待結果　主要テキストと操作が読み取れ、時刻入力から同じ編集を完了できる。
