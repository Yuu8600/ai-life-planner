# V2の設計判断

| 項目             | 採用した初期値・設計                                                                                                                                                                               |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 緊急Task         | 期限が当日か翌日なら初回の集中配置を最大2枠試す。通常Taskの初回を試した後も空きがある限り追加配置する。                                                                                            |
| 同順位           | 期限、重要度、Taskの直近完了、Goalの直近完了、登録時刻、IDの順。完了記録は読み込んだ直近90日と対象日を使う。                                                                                       |
| 当日の自由時間   | 初回生成の `U` は現在時刻を分単位で切り上げた時刻から活動終了まで。25%は分単位で切り上げ、`U` で切り詰める。後ろの連続枠に入れば1枠、どこにも入らなければ後ろから分割する。                        |
| 余裕時間         | 異なるTaskの間に連続した空き30分。設定の範囲は0〜240分。固定・移動・生活・自由時間を空きに含めない。                                                                                               |
| 柔軟な生活予定   | 終了制約が早い順、同率はID順。配置不能は警告し、定義を残す。再計画時は未来の衝突枠を範囲内で移動し、自由時間は保持する。                                                                           |
| 「今日はしない」 | 選んだ1枠だけを取りやめる。同日の同Taskの新規自動追加を停止し、他の保存済み枠は残す。                                                                                                              |
| 「あとで」       | 対象だけの再配置を先に試す。次に未開始・未固定の他の作業枠を最大1つ移す案を試す。入らなければ枠を「あとで」として記録する。                                                                        |
| V1データ         | Goal・Task・プロフィールを共用。日次計画・作業枠はV2専用。V1計画と実行履歴はV1から引き続き取得できる。V2への自動取込は実装していない。                                                             |
| 日付・保存       | 期限は設定TZのローカル日付。既存Taskの期限は従来の時刻から変換する。V2で期限変更時にV1用の従来列も更新する。深夜は既存の活動時間窓を使う。                                                         |
| AI予算           | ユーザー単位、毎月UTC初日リセット、月500,000マイクロドル。リクエスト前に入力のバイト長と最大出力から推定額を予約する。不確定な応答は予約分を保守的に計上する。                                     |
| AI文脈           | 現在の依頼、同スレッドの直近6発言、名前が依頼に含まれるGoal・Task、任意に指定した日と下書き。端末カレンダー名・場所は送らない。AI計画案は対象日と任意のTaskを示し、実際の配置はPlannerが計算する。 |
