# AI Life Planner V2 実装ノート

## Nativeアプリ

- Today・カレンダーは選択日を読み込み、未生成の日だけルールベースで初回保存する。iPhoneカレンダー不可の場合は、ユーザーが選んだ日だけ限定生成を許す。AppStateの前面復帰・タブ再表示で変更を取得する。
- 期限と曜日の候補抽出、優先順、複数枠、固定と移動、柔軟予定、自由時間、Task間余裕は純粋関数にまとめた。手動編集と再計画はPreviewで表示し、保存直前に端末予定とDB入力を読み直す。
- Taskは単発、毎日、曜日指定、週N回を選べる。枠完了とTask本体の完了を分けた。後者はTasks画面で操作できる。固定予定・生活予定の追加／削除、作業枠のドラッグ・時刻入力、固定解除を実装した。
- AIタブには会話一覧・再開、送信、予算表示、下書き編集・選択承認がある。AI生成・調整の下書きはPlannerの確認画面に渡す。同じ日にAI案を承認する場合もPlannerの競合検証を使う。
- Web Demoのプラットフォーム別ルートとメモリ実装を維持した。新規npmパッケージはない。

## 保存と互換性

V1のPlan置換は明細を削除して再作成するため、V2は異なる日次計画テーブルと書き込みRPCを使う。プロフィール・Goal・Taskは共用し、列追加の既定値で既存データを読める。V1のRPC、RLS、活動ログ、Edge Functionの契約は維持する。端末予定のタイトルや位置は日次計画へ保存しない。

Plan保存RPCはユーザーを `auth.uid()` で確定し、同一ユーザーの保存を直列化する。日付・revision・DB入力を照合し、他ユーザーのTask、過去の新規枠、保存済みの実行記録の変更を拒否する。端末カレンダーはDBから参照できないため、アプリ側で再取得して比較する。端末予定読み取りとDB保存の間には短い競合窓が残る。

新しいチャット・メッセージ・下書き・利用量はRLSでユーザー単位。AI呼出し前に認証を確認し、サーバー専用RPCが月間予算を予約する。下書きの承認は1トランザクションで、revision・所有者・変更前値と更新時刻・依存Goalを検査する。

## 残る実装・確認事項

- V1計画・実行履歴のV2自動移行、日付をまたぐ手動枠移動、自由時間を短縮する別承認フローは未実装。自由時間を確保できない衝突は警告を表示する。
- 食事などの移動・「あとで」は局所探索。複数の保護されていない予定を一括で組み替える探索は限定的。配置できない場合は警告を残す。
- AIの下書き修正依頼から返る改訂案は新しい下書きとして保存する。チャット画面は直近100発言を表示する。保存済みの古い発言向けのページ送りは未実装。
- 本番のV1/V2併用、iPhoneへのインストールと操作、実OpenAI APIの応答と費用は利用者の確認が必要。既存iOS bundle identifierを使うため、同一端末にV1とV2を同時導入する場合は別識別子・署名設定が必要。
