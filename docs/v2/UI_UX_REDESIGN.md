# V2の画面改善

| 画面         | 現在の課題                                           | 改善方針                                                                                                                                                             |
| ------------ | ---------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Today        | 一覧と横向きバーから時刻や衝突を読み取りにくい       | V1の時間軸計算を使い、作業枠、固定予定、端末予定、生活予定、自由時間を縦方向に並べる。タップで詳細、長押しして上下移動で変更確認。数値入力と状態変更は詳細から開く。 |
| Calendar     | Todayと作業枠の操作が重複する                        | 日付ごとの予定の確認と登録に集中する。確定した作業枠の操作はTodayへ戻る。                                                                                            |
| Goals・Tasks | 一覧上の管理操作や入力項目が増えると主操作が埋もれる | 追加を明確にし、詳細な操作や補助項目は必要な場面で開く。共通のフォーム・色・ボタンを使う。                                                                           |
| AI相談       | 会話が長くなるほど入力や下書きへの移動に手間がかかる | 入力へ戻りやすくし、相談日の指定は任意操作にする。下書きでは選択件数を表示して承認内容を確認しやすくする。                                                           |
| Settings     | 計画に関する設定の保存場所が離れている               | Planner設定を近くにまとめ、保存の単位をボタン名で伝える。                                                                                                            |

小画面では時刻・カード・操作が読める幅を優先する。作業枠の変更案は現在のPlanner検証と承認画面を通す。端末予定は読み取り専用で扱う。

## 実装の要点

- Todayの枠は開始時刻と所要時間で描画する。初期表示では現在時刻または予定のある時間帯付近から表示する。「一日全体を表示」で早い時間帯も見られる。終日の端末予定はタイムライン上部に表示し、複数の予定が重なる場合は列を分ける。「作業枠を探す」から、短い枠や「あとで」「今日はしない」にした枠も開ける。
- 長押し後の上下移動は5分単位。ドラッグ中に候補時刻を表示し、ドロップ後に既存のPreviewを作る。時間が重なるなどの理由で置けない場合は作業枠を動かさず理由を表示する。長さを変更したい場合は詳細から開始・終了時刻を入力する。
- Calendarは選択日の固定予定・生活予定・iPhone予定を管理・参照する。その日の作業枠に対する操作は「この日の作業計画を開く」から行う。
- GoalsとTasksは項目名から編集し、「その他」から完了や削除などの操作を開く。TasksのGoal候補は必要に応じて展開する。AI相談はメッセージ入力欄を下部に置き、対象日を任意の条件にした。Settingsは計画関連項目の近くに作業枠の間隔を配置した。
- Plannerのルール、データ形式、DB、保存RPCは既存のまま。V2の履歴機能はこのブランチに含まれる。手動操作は [チェックリスト](MANUAL_TEST_CHECKLIST.md) の「V2 UI改修」を参照する。
