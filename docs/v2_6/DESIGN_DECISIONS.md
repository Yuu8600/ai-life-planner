# V2.6 設計判断

推薦には、端末上で取得した時間帯と既存の見積もりを使う。重なった予定は進行中の区間を統合し、取消済み・空き指定を除く。終日予定は時間を占有する指定がある場合に限って使う。次の予定までの時間は暦上の参考値で、本人が使える時間は従来の15・30・60分から指定する。予定の取得失敗時にもTask情報で推薦する。

当日・翌日の期限を先に確保し、承認した優先・短時間方針とカレンダーに収まる見積もりを推薦順に反映する。候補を絞る方針でも緊急候補はすべて表示できる。方針は設定TZの日付で開始日と終了日を含めて評価し、同じ種類・対象なら手動、作成日時、IDの順で決める。

共有なしは既定。予定の有無だけ、または選んだ予定のタイトル・日時を共有できる。場所は独立した選択。iOSの取得結果には非公開属性が提供されないため、終日と私的な予定は本人が選別する。共有する回答はセッション内だけに表示し、送信文・回答・下書きをDBに保存しない。モデルが予定名を回答に復唱する場合も保存を防ぐため、共有回は読取相談に限定する。承認付きの変更は共有なしの別送信で扱う。
