# V2.6 実装前の監査

起点は仕様の基準コミット 093cdd2 を含み、UI簡素化まで入った feat/v2-5-daily-ux の 01a6ed1。追跡済みの変更はなく、未追跡の仕様原本と既存QAメモは作業ツリーに残した。仕様はルートにあった同名原本をこのディレクトリに複製した。作業ブランチは feat/v2-6-ai-calendar-integration。

| 領域          | V2.5の実装とV2.6の差分                                                                                                                             |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 今日・タスク  | 名前だけの登録、カレンダー非依存の推薦、単発・繰り返しの日別実績と取り消しがすでにある。最新UIでは時間だけを一箇所で選び、完了済み一覧を分離済み。 |
| 予定          | DayAgenda が端末予定とアプリ内固定予定を個別に取得していた。端末の読取結果を使い、推薦用の時間情報を同じ取得から導出する。                         |
| AI            | v2-chat が認証、予算予約、履歴、Task・Stepの下書き生成を扱う。端末予定の送信は未対応。今回共有レベルと送信プレビューを追加する。                   |
| 承認          | v2_drafts、リビジョン付き編集と原子的な選択承認を再利用。却下、期間付き推薦方針、編集直後の取り消しが新規。過去の目標提案は閲覧用に残す。          |
| 高度なPlanner | 分離済み。既存の予定編集と履歴を再利用する。推薦には自動時刻配置を入れない。                                                                       |
