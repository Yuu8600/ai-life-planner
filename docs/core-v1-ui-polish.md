# Core v1 UI / UX polish

実施日: 2026-11-05–06（Asia/Tokyo）。Core v1の機能を増やさず、既存の緑系theme、
feature構造、保存・実行・再計画の設計を保って公開前の表示を整えた。

Activity Logとshared componentsをコードから確認し、次の改善案を提示した。
規模の「小」は主に文言・配置・style、「中」は既存コンポーネント間の調整を指す。

## 改善内容

- 共通UI: 見出しの余白と文字スタイル、補助テキストの濃さ、48pt以上の共通ボタンと長いラベルの折り返しを整えた。
- 空・読み込み・エラー: 6 featureのStatePanelをsharedへ寄せた。各featureのtestID、読み込みラベル、再試行処理、disabledは維持している。
- Today: 挨拶を中心とした見出しから「今日の予定」へ変更。Actionと同名のTask名、定型理由、冗長な種別ラベルを画面から減らした。理由はPreviewと読み上げ用の説明に保持した。
- Todayの強調: 既存の時刻順リストで最初のscheduled Actionに「次に取り組む」を表示する。新しい推薦・優先度・時刻判定の規則は加えていない。
- Planner: 表示名・読み上げ名をPlannerに揃え、内部routeの`ai`は維持。ルールベースが標準でAPI設定不要、OpenAIが任意であることを説明する。
- Preview: 「保存」を用語として揃え、未保存・保存中・保存済みを区別。保存成功後だけ「今日の計画を見る」を表示し、既存のTodayへ移動する。再保存・Provider再実行は行わない。
- Goals / Tasks: 追加ボタンを先頭へ移動。長い名前と操作欄が競合しないようfooterや値の列を折り返す。
- Calendar: 端末予定は変更せずPlannerが利用すること、空き枠数と合計分数を説明する。選択日からの新しい計画作成機能は追加していない。
- Settings: キーボード回避、情報行の折り返しを調整。未実装の自動調整を設定できるような案内を、現在使える機能の説明へ置き換えた。
- Login / Activity Log: 目標・タスクとCalendarから一日の計画を作る価値、完了・スキップで履歴が残ることを説明する。

## 変更しなかったもの

Plannerの候補選定・配置・validation、日付・timezone計算、Calendar権限や正規化、
Supabase repository / RPC / schema、Auth、Complete / Skip、同日置換、Replanning、
Stale Preview Guardの業務処理は変更していない。OpenAI Providerの実行も対象外。

依存追加・native再生成・大規模UIライブラリ・全画面のデザイン刷新は行っていない。
requirementsも変更していない。カードやフォームを全面抽象化せず、既存のfeature境界を保った。

## 回帰確認

既存テストの文言・アクセシビリティ名の期待値を更新した。Todayの理由は画面上の重複を減らしたため、
読み上げ用ラベルに保持されていることを検証するよう変更した。

`today-timeline.test.tsx`では、完了・スキップ済みを除いた最初のscheduled Actionを強調し、
完了後の再描画で次のActionへ強調が移ること、全件実行済みなら強調しないことを確認する。
既存のPlanner保存テストは、保存成功前にTodayへのボタンが出ないこと、押しても保存を再実行しないことまで確認する。

品質チェックは`npm run typecheck`、`npm run lint`、`npm run format`、
`npm run format:check`、`npm run test:ci`、`git diff --check`がすべて成功した。
Jestは52 suites / 484 tests成功（変更前51 suites / 482 tests）。
