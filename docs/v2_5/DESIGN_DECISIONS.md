# V2.5の設計判断

## 日常の入口

Nativeのタブは「今日」「タスク」「予定」「AI相談」の4つ。「今日」は開いた時点で最大3件を表示し、「今から何する？」では時間と余裕を選んで候補を1件ずつ確認する。15・30・60分と「軽め・ふつう・集中できる」の選択はアカウントごとに端末に保存する。初期値は30分・ふつう。

「タスク」から「目標」とタスク詳細の「小さな行動」を開く。目標との紐付けは任意。「予定」は端末予定とアプリ内の固定予定を表示する。利用可能時間は本人が入力する。

時間割Plannerと生活予定の管理は「設定」から開く。過去のAI計画下書きも確認時にこのPlannerへ進む。V1の計画・活動履歴は時間割Planner内の日付を選んで参照する。公開Web Demoは従来のV1ベースの体験を使う。

## 推薦ルール

- 設定タイムゾーンの暦日を基準にする。V2の活動時間窓が日をまたいでいても、推薦履歴の日付は午前0時で切り替わる。
- 当日・翌日の期限を優先する。同じ優先群では時間目安の有無、優先度、期限、前回の完了日、登録日時、IDで順位を決める。先頭以外は同じ優先群の中で、可能なら異なる目標を選ぶ。
- 期限切れの単発タスクは「期限を見直す」へ案内する。曜日指定にはV2で保存済みの曜日を使う。
- 一つのタスクから候補は1件まで。時間内に収まる小さな行動を優先し、時間未設定の候補には未設定と表示する。長い作業しか残っていない場合は、本人が選んだ時間を初期値として小さな行動の作成を開く。
- 「軽め」「集中できる」は負担を明示した小さな行動の絞り込みに使う。「ふつう」ではどの負担も候補になり得る。
- 「別の候補」は画面上の当日の除外を変更する。「今日は見送る」は保存するため、再起動しても当日は候補から外れる。

## 完了と下書き

単発タスクを推薦から完了するとタスク本体と履歴を同時に更新する。繰り返しタスクは当日分だけ記録する。小さな行動は既定で一度きりとし、必要に応じて繰り返し使える。小さな行動の完了は親タスクや目標の状態を変えない。

AI相談は文章を入力して送信すると新規会話を開始する。タスクを対象にすると小さな行動、目標を対象にするとその目標に紐づく具体的なタスクを提案する。項目編集・選択・承認には従来の下書きを使う。既存の会話・下書き履歴と月間推定予算を使い、端末予定の名前・場所はAIに渡さない。
