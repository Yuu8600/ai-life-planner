# V2.5 日常操作の改善

| 原則           | 対応                                                                                                                     |
| -------------- | ------------------------------------------------------------------------------------------------------------------------ |
| 直感性         | 今日とタスクで、空のチェックを押すと完了。チェックを外すと未完了へ戻る。                                                 |
| 一貫性         | 両タブで同じチェック部品を使用。ラベルと読み上げ名で操作を区別する。                                                     |
| シンプルさ     | 今日に「今から何する？」の条件とおすすめを統合。時間だけを選ぶ。タスク一覧は未完了を表示し、「完了済み」は別画面で開く。 |
| 効率性         | おすすめはまず4件、続きは「もっと見る」。タスク名を押して直接編集でき、追加時の任意項目も同じフォームにある。            |
| 状態の可視化   | 今日の「実行履歴」とタスクの当日実施表示で変化を確認できる。保存処理中は連続操作を抑止する。                             |
| 誤操作防止     | 削除は編集画面から確認を経て実行。単発と繰り返しの完了・取り消しはサーバー側で整合させる。                               |
| 操作の自由度   | 完了と見送りを取り消せる。今日では操作直後に「元に戻す」を押せる。                                                       |
| 認知負荷の軽減 | おすすめ理由を最大2点に絞った。曜日指定は選択数から週の回数が分かる。                                                    |
| エラー対応     | 保存や読み込み失敗時は日本語で案内。日付や結果が別の操作で変わった場合は再読み込みできる。                               |
| モバイル最適化 | タスク名とチェックの押下領域を分け、44pt以上を確保。文字サイズに合わせてタスク名と理由を折り返す。                       |

## 各画面

- 今日のおすすめには今日・明日が期限の候補も残し、使える時間を超える場合は所要時間の目安を添える。最初の4件では目標の分散を維持する。
- タスクのフォームでは名前だけを必須にした。内部の「未予定」「予定済み」などは通常のフォームから外した。既存の「週N回」と「曜日指定」は同じ曜日選択で編集できる。
- 目標の空画面から、タスクと紐付ける場所を案内する。予定タブは既存の日付切り替えと予定の参照・編集を使い、カレンダーの失敗は予定欄に表示する。今日から予定タブへのボタンは表示しきれない予定がある場合に出す。
- AI相談の残り予算は短く表示する。会話・下書き・承認を維持する。時間割と固定・生活予定の管理は、設定の「高度な計画」から開く。

## 保存と互換性

取り消しには認証・所有者・当日の結果を照合するRPCを追加した。単発は完了前の内部状態を復元する。旧V2.5の完了記録には元の状態がないため、当日の単発タスクを戻す場合は「未予定」にする。過去に完了したタスクをタスク一覧から再開しても、過去日の実施履歴は保持する。繰り返しと見送りはその日だけの結果、小さな行動は親と独立した結果として扱う。旧V1・V2の時間割・実行履歴を共用している画面には従来の入口がある。
