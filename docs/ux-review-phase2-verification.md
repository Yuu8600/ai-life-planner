## R-04 / R-12：予定編集・空き時間

### 実装と設計

- `DayAgenda.tsx`：アプリ内固定予定の編集ボタン、活動時間内の空き時間合計・空き枠を追加。
- `FixedEventRepository.ts` / `SupabaseFixedEventRepository.ts`：本人の固定予定だけを更新。
  更新前のタイトル・開始・終了を照合し、競合時は保存を拒否して再読み込みを案内。
  `plan_date`、移動時間など編集対象外の情報は更新しない。
- `EventEditor.tsx`：既存予定を初期値に使用。未変更の時刻は秒・UTC instantを保持。
  共通の未保存確認、保存ロック、エラー時の入力保持を継続。
- `useV25Date.ts` / `V25DailyRoutes.tsx`：設定済み活動時間・タイムゾーンを共有し、保存後再取得。
- 空き時間は既存の公開 `calculateFreeTime` を使用。最低空き時間・余白・翌日終了を反映。
  終日予定の扱いは日常カレンダーの既存仕様を維持。読み込み欠落時は参考表示を明記。
  端末カレンダーの予定は読み取り専用のまま。

### 操作導線

- 変更前：予定を削除して再作成。変更後：予定行の「編集」→修正→保存。
- 変更前：予定一覧から空き時間を暗算。変更後：活動時間内の空き枠と合計を一覧の上で確認。

### 検証

- 関連Jest：4 suites / 21 tests成功。
  新規 `phase2-calendar.test.tsx`：編集対象、通常・権限欠落時の空き枠、翌日活動時間、保存失敗・再試行・秒保持。
- 型チェック、ESLint、全Prettier、全Jest（84 suites / 805 tests）、Web出力・検証、`git diff --check`成功。
  既存未追跡資料の整形違反を混在させないため、HEAD＋今回差分だけの隔離コピーで全体チェックを実施。
- iPhone 17e / iOS 27.2 Simulator、現在コードの `npm run ios:qa` 成功。
  予定作成→編集→キーボード表示→未保存確認→編集継続→保存→一覧反映→削除を実操作で確認。
  空き時間合計が900→840→900分と追従。今回作成した予定だけ削除済み。

## R-05 / R-15・R-06のうちDB不要部分：AI相談

### 実装と設計

- `ChatScreen.tsx`：提案付き応答もAI本文を保持し、実際の保存状態は別の提案カードで表示。
  未利用・予算切れ・状態確認中は入力エリアを非表示。保存済み会話と提案は閲覧可能。
  新規会話は入力開始用の画面だけを開き、最初の明示送信で初めて作成。送信失敗後も同じIDで再試行。
  相談文・共有選択・インライン下書きの未保存編集から離れる際は共通確認を使用。
- `DraftEditor.tsx`：期限・方針の開始終了・計画日を共通ピッカー化、日付表記を統一。
  モーダルの未保存ガードと会話画面へのdirty通知を追加。日付選択自体は保存・承認を実行しない。
- `V25DailyRoutes.tsx` / `V2ChatRoute.tsx`：予定タブからの日付付き共有準備を明示パラメータで渡す。
- `CalendarShareEditor.tsx` / `readCalendarForShare.ts`：対象日のアプリ内・端末予定を自動で確認用に読む。
  自動選択・送信はしない。場所は初期非共有。最大12件、対象日変更時は選択をリセット。
  読み込み中でも閉じられ、遅い応答は無視。部分取得時は警告し、不確かな「予定なし」の要約送信を禁止。
  共有なしでは不要な日付入力を隠し、確認ボタンの意味を整理。

### 操作導線と検証

- 変更前：提案付き返答では説明が消える／日付は文字入力。変更後：説明＋操作カード／日付ピッカー。
- 変更前：予定→AI→参照情報→方法→読み込み→選択→確認。変更後：予定→AIで確認シート→選択→確認。
- 新規会話を開くだけではDB行を作らず、未利用時の無効入力欄も表示しない。
- 全体の型チェック・ESLint・Prettier・全Jest（86 suites / 816 tests）・Web出力／検証・`git diff --check`成功。
- `phase2-chat.test.tsx`：空会話抑止、失敗再試行時のID再利用、未利用時の履歴閲覧、共有自動準備と非送信、
  読込中キャンセル・遅延応答、権限欠落と部分取得、提案日付の未保存確認と明示保存を追加。
- 現在コードのQAビルドでSimulator操作を確認。AIが未設定でも既存会話を開け、無効入力欄がない。
  専用fixtureで説明文・日付編集・未保存確認→破棄、予定タブからの共有シート自動表示・個別選択・確認を確認。
  作成した会話・提案・メッセージ・予定だけを削除済み。実OpenAI APIへの送信は未実行。
- 実送信・ネットワーク失敗・上限はrepositoryをモックした自動テストで確認。Simulatorでは有料AIは使わない。
