# ナビゲーションとPCレイアウト

「今日」「目標」「タスク」「予定」「計画」を表示する。Expo Routerの5ルートは
`/today`、`/goals`、`/tasks`、`/calendar`、`/ai`。タブの名前と選択状態を読み上げに渡し、
選択アイコンの下線と背景で現在地を示す。アイコンはアプリに同梱した線画を使う。
Tabで項目を移動し、Enterで開ける。フォーカスは輪郭線で示す。

スマホWebとNativeは下部5タブ、Webは1024pxから幅184pxの左サイドバーを使う。
外枠は最大1280pxで、画面ごとの最大幅を適用する。設定は独立した画面で最大720px。
静的HTMLの初回描画を揃え、ブラウザで幅が確定してからサイドバーへ切り替える。
Webのタブ履歴にはExpo Routerの `fullHistory` を使い、訪問順に戻る・進むができる。

下部タブは44pt以上の操作領域を確保する。Webはラベルに合わせて高さを広げ、
NativeはDynamic Typeと利用可能幅から高さを決める。最大文字サイズで短いラベルも
収まりにくい場合は、アイコンとアクセシビリティ名を使う。iOSの拡大コンテンツ表示にも
日本語ラベルを渡す。縦向き指定のiPhoneビルドでは、Simulatorで端末を回転させても画面は縦向きになる。

## 未保存の設定から離脱

- iOSでは画面の「閉じる」と左端の戻るジェスチャーが同じルーターの離脱ガードを通る。
  編集継続は下書きを保持し、破棄は元の遷移アクションを再開する。保存中のルート削除は止める。
- Webの「閉じる」は破棄確認を先に行う。ブラウザがキャンセルを許す同一文書の
  戻る・進むではNavigation APIのイベントで確認する。更新、タブを閉じる操作や
  別文書への遷移はブラウザ標準の `beforeunload` に委ねる。
- Navigation APIのないブラウザや取消不可の履歴移動では、同一文書の戻る・進むを止められない。
  `beforeunload` の表示はユーザー操作の有無やOSの終了方法など、ブラウザの判断に依存する。
  履歴はルーターが管理する。
  [HTML Standardの履歴API](https://html.spec.whatwg.org/multipage/nav-history-apis.html#the-navigate-event)と
  [beforeunloadのブラウザ制約](https://developer.mozilla.org/en-US/docs/Web/API/Window/beforeunload_event)を参照。
- 保存済みの内容と下書きが一致すると確認を解除する。アプリの終了やセッション失効は
  ルートの戻る操作とは別に、OSと認証のライフサイクルで処理される。

## Dynamic Typeの調査

Expo 57.0.32、Expo Router 57.0.30、React Native 0.86.3、iOS 27.2 Simulatorの375ptで再現を確認した。
通常文字でTodayまたは設定を開き、起動したまま `simctl ui … content_size accessibility-large`
を実行すると、約214%の文字に変わっても一部の既存Textの行の高さが追随せず欠ける。
逆方向では旧サイズの余白が残る場合がある。固定高や `numberOfLines` を指定していない見出しでも
起きることを確認した。React Nativeの `ParagraphShadowNode` はレイアウトの
`fontSizeMultiplier` を使うが、構築済みのテキスト内容を再利用する。観測結果は
既存テキストの再計測が追随しない挙動と整合する。原因の特定にはネイティブ側の追加調査が必要。

タブラベル、共通の画面見出しとボタン文字だけを、フォント倍率が変わったときに作り直す。
入力値、選択中のタブ、モーダル、保存状態を持つコンポーネントは維持する。
既存の本文・補助ラベル・時間軸などには部分的な欠けが残る。
拡大設定で画面を開き直すか、アプリを再起動すると再計測される。
実機でOS設定から復帰した場合の再現性と、本文の安全な再計測は独立した改善課題とする。

## 確認範囲

Chromeの375、390、768、1024、1440、1920pxで通常文字と200%を検証。
タブ切替、訪問順の戻る・進む、Tab/Enter、モーダルの背面とEscape後のフォーカス、
未保存の戻る確認の編集継続・破棄、再読み込みの標準確認、保存後の離脱を確認した。
Simulatorでは通常、約214%、最大文字サイズで5タブのラベルまたはアイコンを表示。
左端スワイプの編集継続・破棄と、実行中の文字変更で下書きが保持されることを確認した。

比較HTMLはCodexのローカル成果物 `step-9c-5/index.html` に収録した。
実機ではVoiceOver、端末のSafe Area、OS設定からの復帰を、実ブラウザではSafariの履歴確認を確認する。
