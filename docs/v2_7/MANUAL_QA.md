# V2.7 手動QA

V2.7専用のSimulatorアプリ「AI Life Planner V2.7 QA」と分離したSupabase（API `127.0.0.1:56821`、DB `56822`）を使う。ブラウザのWeb Demoは旧デモ用のサンプル体験。端末予定、認証、AI相談を確認するにはNative版を開く。

## AI相談と承認

専用QAのEdge FunctionはOpenAI未設定。まずAIタブで未設定の表示を確認し、Today・Taskが使えることを確認する。以下の実応答を伴う項目は、外部送信と利用料を了承した環境で実施する。

| 操作                                                                                                     | 期待結果                                                                                                                 |
| -------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| 「参照情報」で翌日・「選んだ予定の詳細」を指定。1件を選び、場所をオフで確認し「次の送信に使う」          | 選択した予定だけが内容表示の対象になる。共有設定を確定した段階では送信されない。入力欄では次の送信で共有する件数がわかる |
| 予定を共有して「レポートを優先して、英語の目標は短時間を優先したい」と相談                               | 同じ相談から一時回答と推薦方針を確認できる。回答・相談文と未承認の案は、会話を開き直しても履歴に現れない                 |
| 方針の期間を変更。一部を選択して最終確認し、承認。別の案は却下                                           | 選択した種類・対象・期間だけが保存される。有効日になるとTodayの「推薦方針」に現れる。却下分は反映されない                |
| 通常の相談で複数のTask案を作成。名前と時間を修正し、一件だけ選択して承認                                 | 下書きを開き直さず、修正後の値で適用される。途中で通信が途切れても画面内の編集値が保たれる                               |
| 他のセッションから対象Taskを編集してからAI案を承認。またはAI編集後にTaskを手動で編集してからAIの取り消し | 古い版での適用または取り消しが拒否される。通常の再送で同じTaskが二重に作成されない                                       |
| Todayの方針を解除し、再適用                                                                              | 推薦が方針の選択に追随する。期限が終了すると対象日から外れる                                                             |

## 設定と高度な時間割

1. 設定から「時間割を開く」。保存済みの時間割がない未来日を選ぶ。閲覧と、「時間割の案を見る」→閉じるだけでは保存済みにならない。
2. もう一度案を開いて「この変更を保存」。同じ日を再表示すると保存した時間割が表示される。「作業枠を完了」の結果は枠に記録され、通常のTask完了とは別。
3. 過去の日付で既存の時間割とV1の記録を確認。「時間割専用の設定」で時間割用の活動時間と余白を確認し、通常の地域・時間帯が先に見えることを確認する。
4. 小さな表示領域・大きな文字・VoiceOverで、チェック、行の編集、送信同意、承認のボタンが区別できるか確認する。
